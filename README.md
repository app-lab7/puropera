# ぷろぺた（profiee-app）

平成のプロフィール帳 × 現代アニメゲームUI で、自分のプロフィールを作って見せ合う Web アプリです。

現在はダミーデータだけで動く UI プロトタイプです。Supabase 接続とログインは未実装です。

## 技術スタック

- React
- Vite
- TypeScript
- React Router
- Supabase（接続は今後）

## 起動方法

```bash
cd profiee-app
npm install
npm run dev
```

ブラウザで表示された URL を開き、スマホ幅でトップ画面が出ることを確認してください。

## 依存関係

`react-router-dom` のみ導入済みです。そのほかは実装に入るタイミングで追加します。

| パッケージ | 用途 |
| --- | --- |
| `@supabase/supabase-js` | 認証、データベース、ストレージ |
| `react-router-dom` | 画面遷移（導入済み） |
| `@tanstack/react-query` | サーバーデータの取得とキャッシュ |
| `zustand` | 画面用の軽い状態管理 |
| `zod` | 入力値の検証 |
| `react-hook-form` | プロフィール編集フォーム |

スタイリングは、まずは CSS 変数と素の CSS で土台を置きます。必要になったら Tailwind などの導入を検討します。

## 環境変数

`.env.example` に将来使うキーだけ置いてあります。

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

コピーして `.env` を作っても、現時点のコードは読みません。
